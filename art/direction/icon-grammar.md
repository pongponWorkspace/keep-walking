## 1. ตระกูล icon 4 แบบ

| ตระกูล | ใช้กับ | มุมมอง | สไตล์ | master canvas |
| --- | --- | --- | --- | --- |
| **UI glyph** | navigation, ปุ่มระบบ, สถานะ, quick command | หน้าตรง (flat) | เส้น `ink.900` 2 px เติมสีได้ 1 สีจาก token | 24 × 24 |
| **Item icon** | อุปกรณ์ 4 ช่อง, วัตถุดิบ, ยา, ชุดประดับ, badge | isometric 2:1 ตาม style guide 6.1 | ก้อนกลม ขอบหมึก 2 px แสง 3 ค่าจาก ramp | 64 × 64 |
| **Class badge** | role ในหน้า party, ป้ายจำนวนคนบนรอยแยก, หน้าเลือกพลัง | หน้าตรง | วงกลมพื้นสี class + glyph ขาว | 48 × 48 |
| **Rarity frame** | กรอบรอบ item icon ทุกที่ | หน้าตรง | สี่เหลี่ยมมุมมน ขอบสี rarity + pip + มุมตกแต่ง | 72 × 72 |

กฎแยกตระกูล: class ใช้ **วงกลม** เสมอ · rarity ใช้ **สี่เหลี่ยม** เสมอ · รอยแยกใช้ **รอยแตกซิกแซก** เสมอ · ห้ามสลับรูปทรง เพราะสีบางคู่ใกล้กันโดยเจตนาของ convention (Rare น้ำเงินกับ Tanker น้ำเงิน, Legendary ส้มกับ Ranged ส้มแดง, Epic ม่วงกับ Magic ชมพูม่วง) รูปทรงคือตัวแยกบริบท

## 2. ขนาดและ grid

### 2.1 UI glyph
| ขนาดแสดง | ใช้ที่ | วิธีทำ |
| --- | --- | --- |
| 16 px | inline ในข้อความ, ป้ายเล็ก | **วาดแยกเวอร์ชัน** บน grid 16 · ตัดรายละเอียดภายในทั้งหมด เหลือ silhouette · เส้นยังเป็น 2 px |
| 24 px (master) | ปุ่มทั่วไป, แท็บ, list | grid 24 × 24 · live area 20 × 20 (padding 2 px ทุกด้าน) |
| 32 px | quick command, ปุ่มบนหน้า dungeon | scale จาก master 24 ได้ (เส้นกลายเป็น 2.67 px ยอมรับได้) หรือวาดแยกถ้าเส้นไม่คม |
| 48 px | หน้าสถานะเต็มจอ (auto-retreat, ผ่าน gate) | scale จาก 24 และเพิ่มเส้นขอบเป็น 3 px |

Keyline ใน live area 20 × 20 (ให้ glyph ทุกตัวมีน้ำหนักเท่ากัน)
| รูปทรง | ขนาดใน grid 24 |
| --- | --- |
| วงกลม | เส้นผ่านศูนย์กลาง 20 |
| สี่เหลี่ยมจัตุรัส | 18 × 18 มุมรัศมี 3 |
| สี่เหลี่ยมตั้ง | 16 × 20 |
| สี่เหลี่ยมนอน | 20 × 16 |

- ทุกจุดยึดอยู่บน pixel เต็มหรือครึ่ง pixel ตามแนวเส้น 2 px (เส้นตรงวางกึ่งกลางบนเส้น grid คู่ เพื่อให้ขอบคม)
- touch target ของ icon ที่กดได้คือ ≥ 48 × 48 px เสมอ ไม่ว่า glyph จะเล็กเท่าไร (padding รอบ glyph · ตัวเลขสุดท้ายของ uiux-designer)

### 2.2 Item icon
- master canvas 64 × 64 · ตัววัตถุอยู่ใน 56 × 56 (padding 4 px) · วางฐานวัตถุที่ y = 56 เพื่อให้เงาตกกระทบอยู่ในกรอบ
- ขนาดแสดง: 48 px (list, ป้ายรางวัลใน tick), 64 px (inventory), 96 px (หน้าตีบวก, รายละเอียดไอเทม) · SVG scale ได้ตรง ไม่ต้องวาดแยก
- เส้นขอบ 2 px ที่ 64 · ใน 48 px ต้องยังเห็นเป็นเส้นต่อเนื่อง (ตรวจด้วยการ render จริง)

### 2.3 Class badge และ rarity frame
- class badge: 20 px (ป้ายบนแผนที่), 32 px (list party), 48 px (master, หน้าเลือกพลัง, profile)
- rarity frame: 72 × 72 (master รอบ item icon 64) · compact 52 × 52 (รอบ item icon 48) · ขนาดเล็กกว่านี้ห้ามใช้กรอบ ให้ใช้ chip ชื่อ rarity แทน (หัวข้อ 4.4)

## 3. เส้น การเติมสี และรูปทรง

| กฎ | UI glyph | Item icon | Class badge |
| --- | --- | --- | --- |
| เส้นรอบนอก | 2 px `ink.900` | 2 px `ink.900` | ขอบวง 2 px `ink.900` |
| เส้นใน | 2 px (ไม่มีเส้น 1 px ใน glyph) | 1 px `ink.700` | ไม่มี |
| ปลายและมุมต่อ | round cap, round join | round | round |
| รัศมีมุม | 2 px ขั้นต่ำ (ยกเว้นลูกศรและรอยแยกที่แหลมได้) | ตาม style guide 5 | — |
| การเติมสี | ไม่เติม (outline) หรือเติม 1 สี token | ramp 3 ค่า + ไฮไลต์ `bg.surface` 1 จุด | พื้นสี class, glyph `bg.surface` |
| สถานะ active / selected | เปลี่ยนจาก outline เป็นเติม `ink.900` (ไม่ใช่แค่เปลี่ยนสี) | กรอบหนาขึ้น 1 px + เงาทึบ 4 px | ขอบ `accent.signal` 3 px นอกขอบหมึก |
| ห้าม | gradient, เงา blur, ความโปร่งใส, ตัวอักษรใน icon | gradient, texture, ตัวอักษร, โลโก้ | ข้อความขาวบนพื้น class |

หลักการเลือกสไตล์ UI glyph
- **outline** สำหรับ navigation และปุ่มที่เป็นกลาง (แผนที่, กระเป๋า, ตั้งค่า)
- **เติมสี semantic** สำหรับสถานะ (ผ่าน gate = เติม `state.success`, HP ต่ำ = เติม `state.danger`) · สีเติมอยู่ภายในเส้น `ink.900` เสมอ จึงอ่านออกด้วยรูปทรงแม้สีหาย
- icon ห้ามมีตัวอักษรหรือตัวเลขในตัว (ข้อความไทยมาจาก copy key ของ narrative-designer วางข้าง icon)

## 4. สี rarity 5 ระดับ และกรอบ

ระดับเรียงตาม GDD: Common, Uncommon, Rare, Epic, Legendary · ชื่อที่แสดงมาจาก copy key (เสนอ `rarity.common` ถึง `rarity.legendary`) · rarity บอกด้วย **4 ช่องทางพร้อมกัน**: สี, จำนวน pip, ความหนาและชั้นของขอบ, มุมตกแต่ง · ถ้าตัดสีออก ยังเหลือ 3 ช่องทาง

### 4.1 ตารางหลัก
| ระดับ | Token | Hex | pip | ขอบ (ที่ 72 px) | มุมตกแต่ง | ข้อความใน chip | กรอบบน paper / surface / night |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Common | `color.rarity.common` | #888899 | 1 | 2 px ชั้นเดียว | ไม่มี มุมมนเรียบ | `ink.900` (4.96) | 3.30 / 3.48 / 4.96 |
| Uncommon | `color.rarity.uncommon` | #119933 | 2 | 3 px ชั้นเดียว | มุมซ้ายบนมีแถบสามเหลี่ยม 10 px | `ink.900` ตัวหนา (4.63) | 3.54 / 3.73 / 4.63 |
| Rare | `color.rarity.rare` | #2266EE | 3 | 3 px + เส้นใน `ink.900` 1 px ห่างเข้าไป 3 px (ขอบคู่) | มุมซ้ายบนและขวาล่างมีแถบสามเหลี่ยม 10 px | `bg.surface` (5.00) | 4.74 / 5.00 / 3.46 |
| Epic | `color.rarity.epic` | #9933DD | 4 | ขอบคู่แบบ Rare | แถบสามเหลี่ยม 10 px ครบ 4 มุม | `bg.surface` (5.42) | 5.14 / 5.42 / 3.19 |
| Legendary | `color.rarity.legendary` | #DD6600 | 5 | 4 px + ขอบคู่ | ดาว 4 แฉก 14 px ครบ 4 มุม (เติม `rarity.legendary` ขอบ `ink.900` 2 px) | `ink.900` (4.92) | 3.33 / 3.51 / 4.92 |

ทุกค่าผ่าน: ข้อความใน chip ≥ 4.5 · กรอบ ≥ 3.0 บนพื้นหลักทั้ง 3 แบบ

### 4.2 โครงกรอบ master 72 × 72 (วัดจากมุมซ้ายบน)
1. พื้นใน: สี่เหลี่ยม 72 × 72 มุมรัศมี 12 เติม `bg.surface` (ทุกระดับเหมือนกัน ห้าม tint พื้นด้วยสี rarity เพราะทำให้ item icon อ่านยากกลางแดด)
2. ขอบนอกสุด: เส้น `ink.900` 2 px รอบสี่เหลี่ยม (ทุกระดับ ทำให้กรอบเห็นได้แม้บนพื้นที่ contrast กับสี rarity ต่ำ)
3. ขอบสี rarity: ถัดเข้ามาจากขอบหมึก ความหนาตามตาราง 4.1
4. เส้นในของขอบคู่ (Rare ขึ้นไป): `ink.900` 1 px ห่างจากขอบสีเข้าไป 3 px
5. มุมตกแต่ง: วางทับมุม ยื่นออกนอกกรอบได้ไม่เกิน 4 px (เผื่อพื้นที่ใน layout)
6. แถว pip: ข้าวหลามตัดขนาดรวมเส้น 10 × 10 px เติมสี rarity ขอบ `ink.900` 2 px ระยะห่าง 3 px · จัดกึ่งกลางแนวนอน · จุดกึ่งกลาง pip อยู่บนขอบล่างของกรอบ (ครึ่งบนในกรอบ ครึ่งล่างนอกกรอบ) · 5 pip กว้างรวม 62 px
7. item icon 64 × 64 วางกึ่งกลาง ตัววัตถุต้องไม่ทับแถว pip (ฐานวัตถุที่ y = 56 ของ icon)

### 4.3 กรอบ compact 52 × 52
- ขอบหมึก 2 px + ขอบสี rarity 2 px ทุกระดับ (ความหนาไม่ใช้เป็นตัวแยกในขนาดนี้)
- pip 6 × 6 px เติม `ink.900` (ไม่ใช่สี rarity เพื่อให้เห็นชัดที่ขนาดเล็ก) ระยะห่าง 2 px ที่ขอบล่าง
- มุมตกแต่ง: เฉพาะ Legendary (ดาว 10 px ที่มุมขวาบนมุมเดียว) · ระดับอื่นไม่มี

### 4.4 Chip ชื่อ rarity (ใช้ในข้อความ, tooltip, list ที่ไม่มีที่สำหรับกรอบ)
- สูง 24 px มุม 999 px พื้นสี rarity ขอบ `ink.900` 2 px ข้อความตัวหนา 14 px ตามสีในตาราง 4.1
- ด้านซ้ายของข้อความมี pip ย่อ 6 × 6 จำนวนตามระดับ (`ink.900` บนพื้นสว่าง, `bg.surface` บน Rare/Epic)
- chip ใช้ได้ทุกพื้นหลัก เพราะ contrast ของข้อความคำนวณกับพื้น chip เอง

### 4.5 ข้อห้ามเฉพาะ rarity
- Legendary ห้ามใช้มงกุฎ รัศมี ฉัตร หรือสีทองเมทัลลิก (style guide 8.2) · ใช้ดาว 4 แฉกเท่านั้น · ห้ามดาว 5 แฉกคู่ธงหรือดาว 6 แฉก
- ห้ามใช้ความโปร่งใส ประกาย หรือ animation วนเพื่อบอกระดับ (motion ของ rarity เป็นเรื่องของ vfx-animator ใน P1-F03-T27 และต้องไม่ใช่ช่องทางเดียวที่บอกระดับ)
- ห้ามใช้สี rarity กับสิ่งที่ไม่ใช่ความหายากของไอเทม (เช่น ป้าย sponsored, ปุ่ม, สถานะ)

## 5. สี class 4 แบบ และ badge

Class ตาม GDD: Tanker, Ranged, Support, Magic · สีมาจากชุด Okabe-Ito (ออกแบบสำหรับผู้ตาบอดสี) · class บอกด้วย **3 ช่องทางพร้อมกัน**: สี, glyph, ชื่อ (ในจอที่มีที่)

### 5.1 ตารางหลัก
| Class | พื้น badge | สีข้อความชื่อ class | Glyph | silhouette ของ glyph (ต้องจำได้เมื่อระบายดำที่ 16 px) | เหตุผล |
| --- | --- | --- | --- | --- | --- |
| Tanker | `class.tanker` #0072B2 | `class.tanker-text` #005588 (7.50 บน paper) | โล่ | โล่กว้าง ขอบบนตรง ล่างมนลงเป็นปลายทู่ 1 จุด · กว้าง ≥ สูง × 0.85 | บังให้คนอื่น (quick command "ช่วยบังหน่อย") |
| Ranged | `class.ranged` #D55E00 | `class.ranged-text` #AA4400 (5.63) | ลูกศร | ลูกศรเฉียงขึ้นขวา 45° หัวสามเหลี่ยมแหลม หางมีขนนก 2 แฉก · เป็น glyph เดียวที่เป็นเส้นทแยง | ตีจากระยะไกล · ห้ามรูปปืนหรือศูนย์เล็ง |
| Support | `class.support` #009E73 | `class.support-text` #006644 (6.67) | หัวใจ | หัวใจอ้วน 2 โค้งบน ปลายล่างมน · เป็น glyph เดียวที่มีรอยเว้าด้านบน | ฟื้น HP ชุบคนในทีม · **ห้ามกากบาทแดงหรือกากบาทบวก** เพราะเป็นเครื่องหมายคุ้มครองของกาชาดตามกฎหมาย |
| Magic | `class.magic` #CC79A7 | `class.magic-text` #994477 (5.78) | ประกาย 4 แฉก | ดาว 4 แฉกเว้าโค้งเข้า (แฉกยาวบนล่าง แฉกสั้นซ้ายขวา) · เป็น glyph เดียวที่มีปลายแหลม 4 จุด | เร่ง exp · **ห้ามดาว 5 หรือ 6 แฉก ดวงจันทร์เสี้ยว ยันต์ อักขระ ตาที่สาม ดอกบัว** |

### 5.2 โครง badge master 48 × 48
1. วงกลมเส้นผ่านศูนย์กลาง 44 px กึ่งกลาง เติมสี class
2. ขอบ `ink.900` 2 px (contrast ขอบกับพื้น class: tanker 3.33, ranged 4.47, support 5.05, magic 5.65 · กับ paper 16.39)
3. glyph เติม `bg.surface` ขอบ `ink.900` 2 px อยู่ใน live area 28 × 28 กึ่งกลาง (glyph ขาวกับพื้น class: 5.19 / 3.87 / 3.42 / 3.06 ผ่าน 3.0 และขอบหมึกรอบ glyph ทำให้ขอบ glyph ≥ 16:1 เสมอ)
4. ไม่มีไฮไลต์ ไม่มีเงา (badge เป็นสัญลักษณ์ ไม่ใช่วัตถุ)

ขนาดเล็ก
- 32 px: เหมือน master scale ลง · ขอบ glyph เหลือ 1.5 px ยอมรับได้
- 20 px (ป้ายจำนวนคนบนรอยแยก): วาดแยก · วงกลม 18 px ขอบหมึก 2 px · glyph ขาว **ไม่มีขอบ** silhouette ตามตาราง 5.1 · ป้ายรอยแยกแสดง "badge + ตัวเลข" เช่น [โล่] 2 [หัวใจ] 1 · ตัวเลขใช้ `ink.900` บนแผ่นรอง `rift.300` (8.79) · ไม่มีจุดหรือตำแหน่งรายคน (NN-4)

### 5.3 การใช้สี class
- ใช้ได้กับ: badge, แถบสีซ้ายของการ์ดผู้เล่นใน party (กว้าง 6 px พร้อม badge เสมอ), ไฮไลต์ในหน้าเลือกพลัง
- ข้อความชื่อ class ใช้ `class.*-text` บนพื้นสว่าง หรือ `bg.paper` บน `bg.night` · ห้ามข้อความขาวบนพื้น class
- ห้ามใช้สี class เป็นกรอบ item icon (กรอบเป็นของ rarity) และห้ามใช้เป็นสีป้ายหรือปุ่มทั่วไป
- quick command "ช่วยบังหน่อย" (เรียก Tanker) ใช้ glyph โล่ แต่เป็น UI glyph ขอบหมึกไม่มีพื้นวงกลม เพื่อไม่ให้สับสนกับ badge

## 6. การแยกได้แม้ตาบอดสี

### 6.1 ช่องทางซ้ำซ้อน (redundant encoding)
| ระบบ | สี | ช่องทางที่ไม่ใช้สี | ผลเมื่อไม่มีสีเลย (ภาพขาวดำ) |
| --- | --- | --- | --- |
| Rarity | 5 สี | pip 1–5, ความหนาและชั้นขอบ, มุมตกแต่ง, ชื่อใน chip | แยกได้ครบ 5 ระดับจาก pip อย่างเดียว |
| Class | 4 สี Okabe-Ito | glyph 4 silhouette ที่ไม่ซ้ำกัน (หัวข้อ 5.1), ชื่อ | แยกได้ครบ 4 จาก glyph อย่างเดียว |
| สถานะ | success / danger / info | icon ถูก / ตกใจ / ข้อมูล และข้อความ | แยกได้จาก icon |

### 6.2 จุดเสี่ยงที่รู้อยู่แล้ว (ยอมรับโดยมีช่องทางอื่นรองรับ)
- Uncommon (L 0.231), Legendary (L 0.249), Common (L 0.251) ความสว่างแทบเท่ากัน · ในภาพขาวดำและในผู้ตาบอดสีแดงเขียว (deutan, protan) เขียวกับส้มดูใกล้กัน → pip และมุมตกแต่งเป็นตัวแยกหลัก ห้ามลดทอน
- Rare กับ Epic ใกล้กันใน protan และ tritan → ต่างกันที่ pip 3 กับ 4 และมุมตกแต่ง 2 กับ 4 มุม
- สี class 4 สีต่างกันใน deutan, protan, tritan ตามคุณสมบัติของชุด Okabe-Ito · Tanker กับ Support ใกล้กันที่สุดใน tritan → glyph โล่กับหัวใจต่างกันชัดที่ silhouette

### 6.3 วิธีทดสอบ (บังคับใน content gate)
1. render style tile และหน้าจอที่มี icon เป็น PNG
2. จำลอง protanopia, deuteranopia, tritanopia และ achromatopsia (ขาวดำ) ด้วยเครื่องมือจำลองที่ใช้ matrix ของ Machado 2009 (เช่น Chrome DevTools > Rendering > Emulate vision deficiencies ซึ่งฟรีและมีอยู่แล้ว)
3. ผ่านเมื่อ: ในทั้ง 4 แบบ ผู้ตรวจระบุ rarity ครบ 5 ระดับและ class ครบ 4 แบบได้ถูก 100% โดยไม่อ่านข้อความ ที่ขนาด 52 px (rarity frame compact) และ 20 px (class badge)

## 8. กฎ SVG และการส่งมอบ

กฎเหล่านี้เป็นส่วนของ icon · naming เต็ม โครง manifest และงบขนาดไฟล์สุดท้ายอยู่ใน `asset-pipeline.md` (P1-F03-T11) ถ้าขัดกัน asset-pipeline ชนะ

| กฎ | ค่า |
| --- | --- |
| viewBox | UI glyph `0 0 24 24` (16 px วาดแยก `0 0 16 16`) · item icon `0 0 64 64` · class badge `0 0 48 48` (20 px วาดแยก `0 0 20 20`) · rarity frame `0 0 72 72` และ `0 0 52 52` |
| raster | ห้ามฝัง raster ห้าม `<image>` |
| ข้อความ | ห้าม `<text>` ห้ามแปลงตัวอักษรเป็น path ใน icon |
| สี | hex จาก token เท่านั้น ใส่ใน attribute `fill` / `stroke` ตรง ไม่มี `opacity` ยกเว้นเงาตกกระทบของ item icon (`ink.900` ความทึบ 0.2) |
| เส้น | ใช้ `stroke` จริง (`stroke-width="2"`, `stroke-linecap="round"`, `stroke-linejoin="round"`) ใน UI glyph เพื่อให้ uiux ปรับสีเส้นได้ · item icon แปลง stroke เป็น path ได้ |
| สีที่ code เปลี่ยนได้ | UI glyph แบบ outline ใช้ `stroke="currentColor"` ได้ (ค่าที่ code ส่งต้องเป็น token) · อย่างอื่นใช้ hex ตายตัว |
| rarity frame | 1 ไฟล์ต่อระดับต่อขนาด (10 ไฟล์) ไม่รวม item icon · code ประกอบ frame + icon เอง |
| class badge | 1 ไฟล์ต่อ class ต่อขนาด (12 ไฟล์ที่ 20/32/48) |
| id ภายใน SVG | ห้าม id ซ้ำข้ามไฟล์ (prefix ด้วยชื่อไฟล์) เพราะ SVG อาจ inline หลายตัวในหน้าเดียว |
| งบขนาดเสนอ | UI glyph ≤ 2 KB · class badge ≤ 3 KB · rarity frame ≤ 3 KB · item icon ≤ 8 KB (หลัง SVGO) |

## 9. Checklist ตรวจ icon (ใช้ใน content gate `art/reviews/F<nn>-visual-gate.md`)

ทุกข้อต้องผ่าน · ข้อที่ตกเขียนเป็น finding พร้อมวิธีแก้
- [ ] อยู่ในตระกูลที่ถูก และใช้รูปทรงประจำตระกูล (class = วงกลม, rarity = สี่เหลี่ยม, รอยแยก = ซิกแซก)
- [ ] canvas และ viewBox ตรงหัวข้อ 8 · glyph อยู่ใน live area และตรง keyline
- [ ] เส้นรอบนอก `ink.900` 2 px ปิดรอบ · ไม่มีเส้นที่มีความหมายบางกว่า 2 px (ยกเว้นเส้นใน item icon 1 px)
- [ ] ใช้เฉพาะ token hex · ไม่มี gradient, blur, texture, `<image>`, `<text>`
- [ ] silhouette ระบายดำแล้วยังจำได้ที่ขนาดแสดงเล็กสุด (16 px glyph, 20 px badge, 48 px item)
- [ ] rarity: สี + pip ครบ + ขอบ + มุมตกแต่งตรงตาราง 4.1 · class: สี + glyph ตรงตาราง 5.1
- [ ] ผ่านการจำลองตาบอดสี 4 แบบตามหัวข้อ 6.3
- [ ] contrast ข้อความใน chip ≥ 4.5 และองค์ประกอบ ≥ 3.0 ตาม style guide หัวข้อ 4
- [ ] ไม่มี motif ในรายการห้ามของ style guide 8.2 และคอลัมน์ "ห้าม" ในหัวข้อ 7
- [ ] glyph ไม่ชนความหมายกัน (หัวใจ = Support เท่านั้น, ดาว 4 แฉก = Magic และมุม Legendary เท่านั้น, แม่กุญแจ = speed lock เท่านั้น)
- [ ] ขนาดไฟล์ไม่เกินงบ
