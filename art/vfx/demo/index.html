art/vfx demos (P2-F05-T05)

These pages load the pre-compiled art/vfx/dist/**/*.js (plain ES modules, no bundler, no game, no dependency) — art/vfx/dist/ is generated from the TypeScript source (art/vfx/{core,tick-feedback,rarity-reveal,rift-reveal}/*.ts) via pnpm exec tsc -p art/vfx/tsconfig.json; rerun that after editing any .ts source. Opening via file:// works directly in Firefox. Chromium and WebKit/Safari block ES module import across file:// resources as a CORS policy (unrelated to this codebase); for those, serve the repo root once with any static server, e.g. python3 -m http.server 8000 from the repo root, then open http://127.0.0.1:8000/art/vfx/demo/. Each demo self-measures with the Performance API.

  • Tick feedback — run.tickGranted / run.tickGrantedFirst / run.tickDenied / run.levelUp
  • Drop reveal, 5 rarity tiers — drop.rarity.common..legendary (V-21)
  • Rift unfold — icon.ui.rift one-shot reveal
  • Visibility + reduced-motion checklist — the mandatory pre-gate checklist from motion-direction §10
