## `style-tile.svg` (1440 × 2720, viewBox เดียวกัน)

ภาพเดียวรวมทุกส่วนตามที่ P1-F03-T13 ต้องการ เรียงจากบนลงล่าง:

1. **Palette / Token (§3)** — สวอตช์สีพร้อม token name และ hex ตรงตัว
   - 1.1 Neutral: `ink.900/700/500/300/100`, `bg.paper/surface/night`
   - 1.2 Accent/Semantic: `accent.signal`, `rift.500/300/700`, `state.danger/success/info` และแถบมืด `bg.night` ที่ใส่ตัวแปร `*-on-night` ไว้ในบริบทจริงที่มันถูกใช้
   - 1.3 Rarity 5 ระดับ พร้อมตัวอย่างข้อความ "Aa" สีที่ถูกต้องบนพื้นแต่ละสี (ตามตาราง §3.3)
   - 1.4 Class 4 สี Okabe-Ito พร้อมชื่อ class ที่เขียนด้วยสี `*-text` (ไม่ใช่สีขาวบนพื้น class ตามกฎ §4.6)
   - 1.5 Material ramp 10 ชนิด แสดงเป็นแถบ 3 ช่อง (top/left/right) ตามลำดับซ้ายไปขวา
   - 1.6 Avatar skin ramp 1–6 และ hair ramp 1–6 (§3.4.1) แถบเดียวกัน — ใช้ได้เฉพาะ layer ของ avatar เท่านั้น ไม่ใช่กับ prop/UI/แผนที่

2. **Shape language (§5–6)** — กล่องอ้างอิง 5 กล่อง: Avatar chibi (หัว:ตัว ≈ 1:1.2), Monster (silhouette ของจริงผิดขนาด + ตา 2 จุด, ใช้นกพิราบเป็นตัวอย่าง), Boss raid (แขนเดียวโผล่จากรอยแยก กินพื้นที่ภาพส่วนใหญ่ ไม่เห็นหัว/ตัว), รอยแยก (ซิกแซกมุมแหลม), UI card/button (มุมมน 12px + เงาแบนทึบเลื่อน 4px ไม่มี blur)

3. **Rarity frame 72 px master (icon-grammar §4)** — กรอบจริงทั้ง 5 ระดับ สร้างตามโครงสร้าง §4.2 ทุกจุด: พื้นใน `bg.surface`, ขอบหมึกนอกสุด, ขอบสี rarity (หนาขึ้นตามระดับ, ขอบคู่ตั้งแต่ Rare), มุมตกแต่ง (ไม่มี → สามเหลี่ยม 1 มุม → 2 มุม → 4 มุม → ดาว 4 แฉก 4 มุม), และแถว pip 1–5 ที่ขอบล่าง **Legendary ใช้ดาว 4 แฉกเท่านั้น ไม่มีมงกุฎหรือรัศมีในไฟล์นี้เลย**

4. **Class badge 48 px master (icon-grammar §5)** — วงกลมพื้นสี class + ขอบหมึก 2px + glyph ขาวขอบหมึกกึ่งกลาง: โล่ (Tanker), ลูกศรทแยง 45° มีขนนกที่หาง (Ranged), หัวใจมีรอยเว้าบน (Support), ประกาย 4 แฉกเว้าโค้ง (Magic) — **ไม่มีกากบาทแดงหรือกากบาทบวกที่ไหนในไฟล์**

5. **Do / Don't — คู่ #1, #3, #4 (style-guide §10)**
   - **#1 มอนสเตอร์**: Do = นกพิราบก้อนกลม ขอบหมึก ตาโต 2 จุด ยืนบนทางเท้า · Don't = ตัวเดียวกันแต่มีหนามจากกล้ามเนื้อ ตาแดง เขี้ยว และเส้นแสงกระด้างแบบ horror (ไม่มีเลือดหรือภาพรุนแรงจริง)
   - **#3 ปุ่มหลัก**: Do = ปุ่ม `accent.signal` ขอบหมึก 2px เงาแบนทึบเลื่อนลง 4px ตรง (ไม่ทแยง) ข้อความ `ink.900` ตัวหนา (contrast 11.43:1) · Don't = ปุ่มไม่มีขอบ ข้อความขาว (contrast ~1.6:1) เงาจำลอง blur ด้วยวงรีซ้อนความทึบต่ำ
   - **#4 กรอบ Legendary**: Do = กรอบ 72px จริงจากส่วนที่ 3 คู่กับ chip ตาม icon-grammar §4.4 (พื้น `rarity.legendary` + pip `ink.900` + ข้อความ "Legendary" สี `ink.900`) · Don't = **จงใจไม่วาดมงกุฎ/รัศมีจริงแม้เป็นตัวอย่างที่ห้าม** เพื่อไม่เสี่ยงแตะกฎ "ห้ามสัญลักษณ์สถาบันพระมหากษัตริย์" (style-guide §8.2) แทนที่ด้วยรูปสี่เหลี่ยมมุมมนสีล้วน (สื่อถึง "บอกระดับด้วยสีอย่างเดียว") ทับด้วยเครื่องหมายห้ามสีแดงและข้อความระบุชัดว่าห้ามอะไรบ้าง — ดู [ASSUMPTION] ด้านล่าง
