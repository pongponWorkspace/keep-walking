### 2.1 เหตุผลของ PASS ราย role (หลักฐาน)

**pillars:** เอกสารอื่นทุกฉบับอ้าง P1–P5, NN-1..NN-8, U1–U8 และหัวข้อ 7 ตรงตามความหมาย ไม่มีเอกสารใดขยายหรือลดความหมายของ pillar · ข้อขัดกันสองจุดที่ pillars ระบุว่ารอ gate นี้ (D-040/D-041 และนิยาม "นอกพื้นที่") ตัดสินในหัวข้อ 4.1 และ 4.5

**narrative:** world.md คง backstory บรรทัดเดียว ไม่มีผู้ถูกเลือก ผู้เล่นไม่เป็นวีรบุรุษ (เสา "ไม่มีใครเป็นวีรบุรุษ") ตรง P5 · ธง HUMAN ครอบเรื่องการเมือง ศาสนา สถาบัน แบรนด์ ครบ (H-02..H-07, H-12) · lore ยาวถูกวางไว้ในหน้าที่ผู้เล่นเปิดเอง ไม่ใช่นาที 0–1 (world.md หัวข้อ 2 กติกาบทพูด) ตรง U8 · copy สามจังหวะ HP ต่ำ / auto-retreat / ตาย คงถ้อยคำ GDD เป็น canon · `run.tickDenied` บอกข้อเท็จจริงไม่ลงโทษ ตรง NN-8 ข้อ 4 · `gps.suspended` ("ช่วงจอดับไม่ได้นับระยะ") บอกความจริงเรื่องช่วงที่ไม่นับ ตรง GDD "สัญญาณขาดและแอปถูกปิด" กฎข้อ 2

**level:** preset 3 แบบตาม GDD "การกำหนด dungeon" ไม่เพิ่ม preset ที่ 4 · ริมน้ำเป็นชั้นที่สอง ชั่วคราวเป็น lifecycle field (D-049) · ทุก preset `verification_mode = continuous_gps`, `floor_level = null` (NN-5) · ศาสนสถานรวมงานวัดตัดทั้งหมด (D-006) · ช่วงเลเวลเป็นแนวทางไม่ใช่การบล็อก (`levelRange.blockEntryOutsideRange = false`) ตรง P2 · เหตุผลว่าสวนหย่อมคุ้มไป (F-15 ของ sim) ทำให้ dungeon ใกล้บ้านมีเหตุผลทางเศรษฐกิจ ซึ่งช่วยเรื่องเดินจริง ไม่ใช่ลด

**audio:** ไม่มี BGM ไม่มี loop สั่นมาก่อนเสียง ทุก cue สำคัญมี visual เป็นชั้นฐาน (direction หัวข้อ 10) ตรง P4 · enhance ห้ามเสียงสล็อตและห้ามขู่ของแตก ตรง NN-6 และ GDD "ระบบตีบวก" · `run.tickDenied` เบาสุดและไม่ใช่เสียง error ตรง NN-8 ข้อ 4 · ระบุความเสี่ยง iOS ไม่มี vibration ตรงไปตรงมา (ดู 4.6)

**liveops (ส่วนที่ผ่าน):** ไม่มี event แข่งขันระหว่างผู้เล่น (calendar หลักการข้อ 5) ตรง NN-4 · dungeon ชั่วคราวมีวันหมดอายุบังคับและตัดเขตศาสนสถาน · เงินจริงและ sponsor เป็น HUMAN ทุกกรณี · playbook ตั้งต้นด้วย 3 ค่าของ GDD และคิด ±20% เทียบค่าตั้งต้น ไม่ใช่ค่าล่าสุด (กันการขยับทีละ 19%)

**uiux (ส่วนที่ผ่าน):** แผนที่คือบ้าน ไม่มีเมนูคั่น · แถบล่างโตตามการปลด ไม่มีทางกดไปหน้าระบบที่ยังไม่ปลด · ไม่มีช่องพิมพ์อิสระทุกหน้า รวม display name (A-P1-F03-T15-3) และลงทะเบียนความสนใจ · Nearby Party แสดงแค่จำนวน + role ไม่มีชื่อ ตำแหน่ง invite · consent location แยกหน้า มีทางกลับไปให้ consent 2 ที่ ลบบัญชีจริง 2 ขั้น · การปิด auto-retreat ฝังลึก 3 ชั้นพร้อม banner ค้างในหน้า run (NN-6) · กดออกได้ทุกเมื่อโดยไม่ต้องเดินออก · run state แยกจาก connection state · หน้าที่บ้านไม่มีรางวัล ไม่มี login รายวัน ไม่มี dungeon เสมือน (pillars 7.3)

### 4.4 ล็อกจอระหว่าง run: ทางเลือก A (Wake Lock + จอพกกระเป๋า) เป็นทิศทาง (components.md หัวข้อ 12, wireframe 03 issue box, A-P1-F03-T16-2)

**คำตัดสิน: CHANGE จากค่าเริ่มต้น B เป็น A** · B ยังอยู่เป็นทางสำรอง

ปัญหา: GDD มีสองข้อที่ชนกันในทางปฏิบัติบนเว็บ v1 · "Core loop ใน Dungeon" บอกว่า "มือถืออยู่ในกระเป๋าได้" ส่วน "สัญญาณขาดและแอปถูกปิด" บอกว่า "ล็อกหน้าจอ v1 บนเว็บ หยุดนับ movement" ถ้าผู้เล่นทำตามข้อแรก (ล็อกจอแล้วเก็บกระเป๋า) เขาเดินจริงแต่ tick ไม่ผ่าน gate · product-manager ชี้ว่าเป็นความเสี่ยงต่อความยุติธรรมของ movement gate (NN-2)

หลักการที่ใช้:
- ข้อ 1 ไม่เกี่ยว
- ข้อ 2 ทั้งสองทางไม่สร้างข้อยกเว้นของ gate · A ไม่ผ่อน gate แต่ทำให้การเดินจริงถูกวัดได้ (หลักฐานการเดินยังมาจาก GPS ขณะหน้าเว็บเปิดอยู่จริง) · ข้อนี้ไม่ตัดสินระหว่าง A กับ B แต่ห้ามทางเลือกใดที่นับระยะช่วงไม่มีหลักฐาน
- **ข้อ 3 ชี้ไปที่ A:** คนที่เดินทางมาและเดินจริงตามที่เกมบอกไม่ควรเสีย tick เพราะข้อจำกัดของ browser · B ทำให้คนทำถูกโดนผลแบบลงโทษทุกครั้งที่ลืม หรือทำให้ต้องถือจอสว่างเดิน ซึ่งขัด P4 ด้วย → เลือก A
- ไม่ขัดถ้อยคำ GDD: ภายใต้ A หน้าจอไม่ได้ล็อก จึงยังจริงว่า "ล็อกหน้าจอ = หยุดนับ" · ไม่ต้องส่ง HUMAN

กติกาของทิศทาง A (uiux เขียนเป็น flow/component, tech-lead ยืนยันความเป็นไปได้ใน Phase 2 ก่อน F04/F05 build):
1. เมื่อเข้า run (หลัง server ยืนยัน B5) client ขอ Screen Wake Lock และแสดง "จอพกกระเป๋า" เป็นค่าเริ่มต้น: พื้นมืดเกือบทั้งจอ มีแค่ HP % และเวลาถึง tick ถัดไป ตัวใหญ่ contrast สูง ไม่มี animation ต่อเนื่อง (P4, art map-style)
2. จอพกกระเป๋าต้องกันการแตะพลาดในกระเป๋า: ไม่มีปุ่มที่มีผลต่อ run บนจอนี้ ออกจากจอพกกระเป๋าด้วย gesture ที่ตั้งใจ (เช่น ปัดขึ้นค้าง) ก่อนจะเห็นปุ่มออกเอง ยา quick command · ปุ่มออกเองยังกดได้ทุกเมื่อหลังออกจากจอพกกระเป๋า (GDD "การออกจาก dungeon")
3. cue สั่น/เสียงของ HP ต่ำ, auto-retreat, ตาย, tick ทำงานได้เพราะหน้าเว็บยัง foreground (ช่วย iOS ที่ไม่มี vibration ดู 4.6)

5. ทางสำรอง B: ถ้า browser ไม่รองรับ Wake Lock หรือขอไม่สำเร็จ ให้แสดง `run.screenLockNotice` ครั้งเดียวต่อบัญชีตาม A-P1-F03-T16-2 (ACCEPT ในบทบาททางสำรองนี้) · ถ้าผู้เล่นกดล็อกจอเองอยู่ดี เมื่อกลับมาแสดง `gps.suspended` ตามเดิม (ข้อเท็จจริง ไม่ใช่ tutorial)
6. ช่วงที่หน้าเว็บ hidden ไม่นับระยะ ไม่ย้อนเติม ไม่ประมาณ (GDD "ไม่มีหลักฐานว่าเดินจริง = ไม่มี reward เพิ่ม") · tick ที่ไม่ผ่านเพราะช่วง hidden แสดงผลเหมือน tick ไม่ผ่านปกติ ไม่ลงโทษ (NN-8 ข้อ 4)
7. ผู้เล่นปิดจอพกกระเป๋าได้ในตั้งค่า "การเดินและความปลอดภัย" (ไม่ต้องยืนยัน) เพราะไม่ใช่ระบบกันตาย
8. เกณฑ์ถอยกลับไป B ทั้งระบบ: ถ้า Phase 2 วัดแล้วแบตต่อชั่วโมงใน run เกินงบที่ tech-lead และ product-manager ตั้ง (GR-12) บนเครื่องทดสอบทั้ง Android และ iOS (D-003) ให้ส่งกลับ game-director ตัดสินใหม่ ไม่ถอยเงียบ

### 4.5 นิยาม "นอกพื้นที่": ใช้ขอบเขตพื้นที่เล่น (mask โซนดำ) ไม่ใช่ระยะถึง dungeon

### 4.9 ร้าน NPC ไม่ใช่ "ตลาด" และต้องมีตั้งแต่จบ run แรก (คำตัดสินใหม่จาก F-01)

- GDD แยกสองระบบชัด: "ตลาด" ในรายการห้ามสอนคือระบบแลกเปลี่ยนระหว่างผู้เล่น (GDD "ระบบแลกเปลี่ยน": listing ไม่ระบุตัวตน ภาษี) ส่วนการขายวัตถุดิบให้ NPC ในราคาคงที่คือ gold source หลัก และยาคือ gold sink หลัก "ใช้ทุก run" (GDD "Gold source", "Gold sink", "ราคา NPC และยา") · core loop ของ GDD มีขั้น "ตีบวก ขายของ อัปเกรด" ต่อจากสรุปรางวัลทันที
- คำตัดสิน: ร้าน NPC (ขายวัตถุดิบให้ NPC, ซื้อยา) เป็นหน้าของตัวเองใน IA ไม่อยู่ใต้ `unlocks.market` · ปลดเมื่อจบ run แรกที่มี tick ผ่าน gate (ไม่อยู่ในนาที 0–10 เพราะยังไม่มีของให้ขาย) · เงื่อนไขเป็น config ของ systems-designer (เสนอชื่อ `unlocks.npcShop` ในรูปแบบเดียวกับ object อื่น) · ไม่จำกัดการขายให้ NPC ต่อวัน (GDD "มาตรการคุมเงินเฟ้อ") · copy แบบรู้ตัวว่าเป็นเกมใช้ได้ที่ร้าน (world.md H-10)
- หลักการที่ใช้: ข้อ 1 ไม่ขัด (NPC ไม่ใช่ตลาดส่วนกลาง และ GDD ตั้งใจไม่จำกัดฝั่ง NPC) · **ข้อ 3 ชี้ชัด:** ถ้าซื้อยาไม่ได้จนถึง L8 (~3 ชม.เดิน) ยาอัตโนมัติไม่มีของให้ใช้ และทางฟื้นจากตาย "ใช้ยาเพื่อฟื้นได้ทันที" หายไป บทลงโทษสูงขึ้นสำหรับคนใหม่ → ต้องแยกร้าน NPC ออกจาก U1 · ข้อ 2 ไม่กระทบ (ขายได้เฉพาะของที่ได้จากการเดิน)
