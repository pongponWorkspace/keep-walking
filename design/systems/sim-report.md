## 4. Drop (`tools/sim/src/drops.ts`, report หัวข้อ 5)

### 4.1 สูตรที่ simulator ใช้

```
ทุก reward tick ที่ผ่าน movement gate ทอยแต่ละ rarity แยกกัน ตัวคูณทุกตัวคูณกัน
rangedTerm = min(1.5, 1 + rangedBuff/100) ถ้ามี Ranged ในดัน · 0.6 ถ้าไม่มี          (drops.json#multipliers)
failTerm   = 1.6 + 0.4 × bossHpFractionLeft ในสัปดาห์หลังล้มบอสไม่สำเร็จ · 1 ถ้าไม่ใช่   (A-P1-F03-T06-16b)
trustTerm  = 0.5 และ Epic / Legendary = 0 ถ้า trust ต่ำ
E[Common]  = (1 + 3)/2 × rangedTerm × failTerm × trustTerm × (0.6 ถ้า dungeon เล็ก)
chance_r   = min(100, base_r × rangedTerm × failTerm × trustTerm × (1.5 ถ้า dungeon เล็กและ r ≥ Rare))
วันต่อ 1 ชิ้น = 1 / (chance_r × นาทีต่อวัน × 60 / 300)
```

## 5. Economy: รายได้เทียบค่ายา (`tools/sim/src/economy.ts`, report หัวข้อ 6)

### 5.1 วิธีคำนวณค่ายา (ไม่รับ 600 เป็น input)

```
grossLoss%/ชม. = (3600 / รอบเฉลี่ย 60 วิ) × hitChance 54% × damagePerHit / maxHP × 100            (damage model ของ T07)
netLoss%/ชม.   = max(0, grossLoss − heal Support × 60 − min(โล่ Magic, grossLoss/12) × 12)
ค่ายา/ชม.      = netLoss / (heal ของยา × (1 + 2% × VIT)) × ราคายา                                   (analytic ไม่มีเพดาน)
Monte Carlo    = เดินต่อเนื่อง 5,000 ชม. ยาอัตโนมัติใช้เมื่อ HP < 40% ฟื้นไม่เกิน max HP (ค่าที่ใช้ตัดสิน)
อัตราส่วน       = รายได้/ชม. (drop model หัวข้อ 4) / ค่ายา/ชม. (MC)
```

สมมติฐาน (ไม่ใช่ค่า balance): เลเวลตรงโซน Z = L = 25, build สมดุลแบ่งแต้ม 4 ทาง, อุปกรณ์ tier ตามเลเวลที่ +0 (VIT 53.75 → โบนัสยา +107.5%), ทุก tick ผ่าน movement gate, ขายวัตถุดิบทั้งหมดให้ NPC, ใช้ยาชนิดเดียวตลอดชั่วโมง, สมาชิก party ถูกทอยตีแยกกันและได้ drop แยกกัน, ตัวผู้เล่นนับใน buff ของ role ตัวเอง (Tanker คนเดียวได้ buff ตัวเอง Support คนเดียว heal ตัวเอง Magic คนเดียวมีโล่)
