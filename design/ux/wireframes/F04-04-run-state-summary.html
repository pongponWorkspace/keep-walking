F1. สรุปผล — manual_exit / dungeon_closed

P
run.summary.headerLabel (สรุป run)
S

run.summary.exited (ออกเอง ของอยู่ครบ)

ตัวอย่างอื่นในหัวข้อเดียวกัน (แสดงทีละสถานะจริง):

run.summary.dungeonClosed (โซนปิดแล้ว ของอยู่ครบ)

run.summaryRewardList (ของที่ได้ใน run นี้) — รายการของจริง

run.summaryContinue (เดินต่อเพื่อรับเพิ่ม)

dungeon_closed (R30, ถึงเวลาปิดระหว่าง run): ของเก็บครบ tick ค้างจ่ายตาม D-059 ไม่ต้องเดินออกเพื่อจบ ไม่ใช่การลงโทษ · ต่างจาก emergency_close ของ moderator (คนละหัวข้อ คนละเหตุ)

ตัวอย่างอื่นในหัวข้อเดียวกัน:

timeout: เวลานอกเกิน suspendedMax_s (R18) เปิดแอปกลับมาเจอหน้านี้ตรงๆ ไม่ใช่จอ run · clock_invalid (E10): นาฬิกาเครื่องเพี้ยน/ถูกตั้งย้อน จบ ณ เหตุการณ์ล่าสุดที่ตรวจได้ ไม่ริบของเดิม
