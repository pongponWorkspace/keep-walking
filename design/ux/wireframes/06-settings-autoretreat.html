E2. หน้าย่อย "การเดินและความปลอดภัย"

P
settings.walkingSafetyLink (การเดินและความปลอดภัย)
S
settings.autoRetreatToggleLabel
(ถอยอัตโนมัติ)
settings.autoRetreatToggleHint (HP ต่ำกว่า {autoRetreatPct}% ระบบพาออกจาก dungeon ให้เอง)

ค่าเริ่มต้น = เปิดเสมอ (config: dungeons.hpSafety.autoRetreatEnabledByDefault (=true)) · เปิด→ปิด ต้องผ่าน popup ยืนยัน (E3) · ปิด→เปิด เปลี่ยนทันทีไม่ต้องยืนยัน

settings.autoPotionLabel (ใช้ยาอัตโนมัติ)
settings.autoPotionThreshold (ใช้เมื่อ HP ต่ำกว่า {autoPotionPct}%)

ปรับเกณฑ์ยาอัตโนมัติ — ไม่ต้องมี popup ยืนยัน เพราะไม่ใช่การปิดระบบกันตายทั้งระบบ · offline: settings.pendingSync (ยังไม่บันทึก รอเน็ต)

settings.pocketScreenLabel (จอพกกระเป๋า)
settings.pocketScreenHint (ปิดจอเป็นจอมืดมี HP ระหว่างเดิน กันแตะพลาดในกระเป๋า)

ค่าเริ่มต้นเปิด (F-04, gate A 4.4 ข้อ 7) · เปิด/ปิดไม่ต้อง popup ยืนยัน ต่างจากถอยอัตโนมัติด้านบน (ไม่ใช่ระบบกันตาย) · ปิดแล้วยัง request Wake Lock เหมือนเดิมเพื่อกัน movement หยุดนับ แค่จอ run แสดงข้อมูลเต็มแทนจอมืด (components.md 12.4)
