run.headerZoneLabel (ลุมพินี)

run.death canon
(คุณตาย ของใน run นี้หายทั้งหมด ครั้งหน้าลองกลับบ้านก่อนตาย)

config: dungeons.death.loseAllRunLoot (=true) — ต่างจาก auto-retreat ต้องสื่อให้ชัด

ทางฟื้น 3 ทาง (เลือกได้บนจอเดียวกัน):

run.death.waitRecover (รอฟื้นเอง)
run.death.waitRecoverDetail (HP กลับมา {recoverPct}% ภายใน {recoverTime})
run.death.usePotion (ใช้ยาฟื้น) — เล่นต่อทันที
run.death.reviveHint (Support ในทีมชุบได้) — อัตโนมัติเมื่อเขากด ไม่ใช่ปุ่มของเรา · แสดงเฉพาะเมื่ออยู่ใน party

ยังอยู่ใน S-03-run ระหว่างรอฟื้น ไม่ถูกเด้งออกเหมือน auto-retreat · ถ้าอยากออกจริงกดปุ่มออกเองได้ตลอด
